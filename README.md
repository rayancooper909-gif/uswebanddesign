# US Web and Design Website#

Marketing website for US Web and Design, built with React, TypeScript, Vite, Tailwind CSS, and shadcn/ui.

## Local development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion
